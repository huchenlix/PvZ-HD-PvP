# PvZ-HD-PvP

植物大战僵尸高清素材与双人对战实验项目，基于 [Patoke/re-plants-vs-zombies](https://github.com/Patoke/re-plants-vs-zombies)。非官方项目，与原作权利人无隶属关系。

## 测试版状态

Windows测试版正在准备。当前候选已完成Release构建及卡片映射逻辑检查，新增卡片和角色对照的实际游戏验证尚在进行。尚未上传可供下载的测试版，不将代码检查称为游戏画面或双机连通通过。

计划通过GitHub Releases提供版本和校验摘要，通过夸克提供镜像，并在植物大战僵尸吧收集反馈。正式下载链接发布后更新本页。
